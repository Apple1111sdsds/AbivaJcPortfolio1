Hi! I'm John Carlo N. Abiva, a dedicated 2D game developer and digital artist. I bridge creative visual design and responsive game architecture — transforming concepts into living game worlds.

For Game Development, I build responsive game loops, state machines, and combat systems using Godot Engine and Unity 2D.

My 2D Art pipeline spans Ibis Paint for ideation, Clip Studio Paint for character concepts and cel shading, Pixel Studio for sprites and tilesets, and Krita for environmental matte art. For 3D, I build low-poly props in Blender.
